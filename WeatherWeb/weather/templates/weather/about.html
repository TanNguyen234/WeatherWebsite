📍 Nominatim (OpenStreetMap)

Geocoding / Reverse Geocoding

  • Tìm địa điểm theo tên:
    GET /api/geocode/?q=Ben Thanh Market
    → Django proxy → nominatim.openstreetmap.org/search
  • Xác định quốc gia của điểm:
    GET nominatim.../reverse?lat=…&lon=…&zoom=3
    → Trả về address.country_code (ISO-2)
Proxy server-side tránh CORS và hạn chế User-Agent của browser.
Miễn phí · Không cần API key

🗺 OSRM (Open Source Routing Machine)

Road Routing Engine

  • Routing 2 điểm:
    GET /api/route-geometry/?slat=…&slng=…&elat=…&elng=…
    → Django proxy → router.project-osrm.org/route/v1/driving/
  • Routing nội địa (cùng quốc gia):
    3-waypoint: start → midpoint → end
    → Buộc OSRM không đi qua lãnh thổ nước khác
  • Trả về: GeoJSON LineString + khoảng cách + thời gian
Leaflet chỉ hiển thị kết quả, không tính toán đường đi.
Cần API key

Dữ liệu không gian

Định nghĩa: Dữ liệu liên quan đến vị trí địa lý

  • Tọa độ (vĩ độ, kinh độ)
  • Điểm, đường, đa giác
  • Phân tích dựa trên vị trí
Ví dụ trong ứng dụng:
  • Vị trí người dùng đã lưu
  • Tuyến đường đường bộ thực tế giữa 2 điểm
  • Thời tiết tại tọa độ cụ thể
  • Kết quả tìm kiếm địa danh

Dữ liệu thời gian

Định nghĩa: Dữ liệu thay đổi theo thời gian

  • Dữ liệu chuỗi thời gian
  • Hồ sơ lịch sử
  • Dự báo & dự đoán
Ví dụ trong ứng dụng:
  • Dự báo theo giờ (24 giờ tới)
  • Dự báo theo ngày (7 ngày tới)
  • Xu hướng thời tiết theo thời gian

Nguyên tắc cốt lõi: Lấy dữ liệu theo yêu cầu, không tích trữ dữ liệu.

Database Schema (PostGIS-Ready)

user_location

  • id SERIAL PK
  • user_id FK → auth_user
  • name VARCHAR(255)
  • latitude FLOAT
  • longitude FLOAT
  • created_at TIMESTAMP

Tương lai: lat/lng → POINT SRID 4326

location_group

  • id SERIAL PK
  • user_id FK → auth_user
  • name VARCHAR(255)
  • created_at TIMESTAMP

route

  • id SERIAL PK
  • user_id FK → auth_user
  • name VARCHAR(255)
  • start_location_id FK
  • end_location_id FK

Tương lai: → LINESTRING
